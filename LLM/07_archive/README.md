# Archive

## Retention rule

Move superseded prompts, decisions, and experiment notes here when they must
remain traceable. Do not silently delete research history. Include the reason,
date, and replacement path in the archived file.

## Purpose and safety boundary

The archive preserves provenance for inactive material; it is not a source of
current guidance. Do not archive secrets, raw waveforms, private catalogs, or
generated artifacts merely to bypass retention or review rules.

An archive entry remains evidence of project history, not current guidance.
Link replacements from the active document and preserve the original review
status.

## Archive entry pattern

```text
active document ──superseded by──▶ replacement
       │                              │
       └───────── archive record ◀────┘
                    │
             reason + date + reviewer
```

### Required metadata

An archived file should identify its original status, archive date, reason for
supersession, replacement path, and any decision or experiment that depends on
it. Archiving is reversible documentation maintenance; it is not permission to
delete source code, data, waveforms, or generated scientific artifacts.
