# Decision log

## Purpose and use

Record stable governance, evidence, path, and approval choices here so that
they are not silently encoded in prompts or scripts. A decision should cite
the repository evidence or human decision that supports it and state when it
must be revisited.

## How to read and extend this log

Use ISO dates (`YYYY-MM-DD`) and link to evidence when available.
Record unresolved path, data, provider, and approval choices here rather than
silently encoding them in a prompt or script. Open issues remain listed in
[`open_questions.md`](open_questions.md).

## Safety and assumptions

This log is documentation, not authorization to access data, run compute,
change code, or publish results. If evidence is incomplete, record the
uncertainty and link the corresponding open question instead of inferring a
project policy.
